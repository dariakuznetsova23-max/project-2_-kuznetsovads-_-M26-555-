# Primitive DB

Учебное консольное приложение на Python.

На текущем этапе реализованы интерактивный цикл,
справка и завершение программы.

## Требования

- uv
- Python 3.12 или новее

## Подготовка
```powershell
uv sync
```

## Запуск
```powershell
uv run database
```

Альтернативный запуск:
```powershell
uv run python -m primitive_db.main
```

## CRUD-операции

Программа поддерживает добавление, чтение, обновление и удаление записей.

Структура таблиц хранится в `db_meta.json`.
Данные каждой таблицы хранятся в отдельном файле `data/<имя_таблицы>.json`.

Файлы создаются относительно текущей рабочей директории.

### Запуск

В окружении проекта:
```bash
uv run database
```

После установки пакета:
```bash
database
```

### Создание таблицы
```text
create_table users name:str age:int is_active:bool
```

Столбец `ID:int` добавляется автоматически.

### Добавление записи
```text
insert into users values ("Sergei", 28, true)
```

ID не передаётся пользователем.
Количество значений должно совпадать с количеством пользовательских столбцов.
Все поля обязательны.

### Просмотр всех записей
```text
select from users
```

### Поиск по условию
```text
select from users where age = 28
```
```text
select from users where name = "Sergei"
```

Поддерживается одно условие равенства.

### Обновление записей
```text
update users set age = 29 where name = "Sergei"
```

Можно обновлять несколько столбцов:
```text
update users set age = 30, is_active = false where ID = 1
```

Столбец ID изменять нельзя.
Если условию соответствует несколько записей, обновляются все подходящие записи.

### Удаление записей
```text
delete from users where ID = 1
```

Удаляются все записи, соответствующие условию.

### Информация о таблице
```text
info users
```

Выводятся имя таблицы, её столбцы и количество записей.

### Дополнительные команды
```text
list_tables
drop_table users
help
exit
```

### Типы данных

- `int` — целое число, например `28`;
- `str` — строка в одинарных или двойных кавычках;
- `bool` — `true` или `false`.

Для вывода записей используется PrettyTable.

### Генерация ID

Новый ID равен максимальному ID среди существующих записей плюс один.
Для пустой таблицы используется ID 1.
После удаления записи с максимальным ID её номер может использоваться снова.

## Декораторы и замыкания

### Обработка ошибок

Декоратор `handle_db_errors` централизованно обрабатывает
ошибки основных операций базы данных: отсутствие таблицы
или столбца, ошибки валидации и файловых операций.

Ошибки ввода, разбора команд и файловых операций оболочки
дополнительно обрабатываются в основном цикле приложения.

После обработанной ошибки пользователь может продолжить
работу с базой данных.

### Подтверждение опасных действий

Перед удалением таблицы или записей программа запрашивает
подтверждение:
```text
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]:
```

Операция выполняется при ответе `y` без учёта регистра
и пробелов по краям. При другом ответе она отменяется.

### Измерение времени

Декоратор `log_time` измеряет время выполнения `insert`
и `select` с помощью `time.monotonic()`.

Пример сообщения:
```text
Функция select выполнилась за 0.001 секунд.
```

Измеряется вызов функции, а не обязательно вся обработка
команды вместе с загрузкой и сохранением файлов.

### Кэширование

Функция `create_cacher()` создаёт замыкание со словарём
для хранения результатов вычислений.

Повторные одинаковые запросы `select` используют
кэшированный результат фильтрации.

Ключ учитывает содержимое данных и условие выборки.
После успешного изменения базы кэш очищается.
Результат выборки возвращается в виде независимой копии.

Кэш хранится в памяти текущего процесса и не сохраняется
между запусками приложения.

### Хранение данных

Метаданные `db_meta.json` и каталог `data/` создаются
относительно текущей рабочей директории.

При запуске приложения из другой папки используется база,
находящаяся в этой папке. Поэтому набор данных может отличаться.
